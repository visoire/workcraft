# Getting help

| You want to | Go to |
| :--- | :--- |
| try WorkCraft without installing it | [workcraft.cc/app](https://workcraft.cc/app/) |
| learn how something works | the [documentation map](docs/README.md), or the in-app documentation (WorkCraft menu, Documentation) |
| ask a question or share an idea | [GitHub Discussions](https://github.com/visoire/workcraft/discussions) |
| report a bug | [a bug report](https://github.com/visoire/workcraft/issues/new?template=bug_report.yml) with your version, system and exact steps |
| report a problem in the docs | [a documentation issue](https://github.com/visoire/workcraft/issues/new?template=documentation.yml) |
| report a security problem | privately, see [SECURITY.md](SECURITY.md); never in a public issue |
| report a bug inside WordCraft, GridCraft, DeckCraft or PdfCraft | their own repositories under [github.com/storytold](https://github.com/storytold) |
| contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

WorkCraft is an alpha project run by volunteers. There is no paid support and no guaranteed response time; questions with a version number, your system and exact steps get answered fastest.
