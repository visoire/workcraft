# WorkCraft 0.1.0-alpha.4

A real document scanner and an Add to Home Screen guide for iPad, a first-start page that fits, a calmer pencil trail and side chat, and newer app builds.

**iPad**

- **Scan a document** in the + menu is now a camera scanner of its own: it finds the page, you drag the corners, pick Grey, Black and white or Colour, add pages and save one PDF in `/Scans`. **Upload files** stays as it was (on an iPad it is Apple's sheet, where Scan Documents is also reachable).
- **Add to Home Screen.** A short notice shows the steps (Share, Add to Home Screen, Add). The same guide is in the main menu. The installed app runs full screen.
- The second page of the first start (choose a workspace) no longer sits too low; Continue is reachable.
- The Focus mode button moved to the top right, away from the Apple Pencil tools. The hover circle is an empty circle, and the pencil trail in an app is one smooth line instead of the beaded snake.

**Side chat**

- The model button is just the provider mark; the approval choice is one button; menus list only the providers that are ready, in the interface font. The @ and / buttons are gone on an iPad.

**Apps**

- OxyBrush 4.0.0-beta.16, Picasso Suite 0.8.0 and ProCraft 0.0.6-beta are installed. The source of OxiGuitar 0.21.1, Retake 0.38.0, Transit 0.7.3 and ProCraft 0.0.7-beta is in the repository folders but has no web build yet.

**Be aware:** this is an alpha. The maintainer tried it on a real iPad (touch and tap and hold work). The scanner with a real iPad camera, the Home Screen notice and the first-start fix were tested in WebKit at iPad sizes only.

Full details: [CHANGELOG.md](https://github.com/visoire/workcraft/blob/main/CHANGELOG.md). Found something? [Open an issue](https://github.com/visoire/workcraft/issues/new/choose).
