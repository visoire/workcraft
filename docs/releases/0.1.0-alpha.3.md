# WorkCraft 0.1.0-alpha.3

Easier to bring files in, a simpler cloud setup, dropdowns for models and addresses, a guide to making WorkCraft faster, and corrected app versions.

**Bring files in**

- The + menu has **Upload files** (on a computer) or **Scan a document** (on an iPad, through the picker sheet of iPadOS). Files land in `/Uploads` or `/Scans` and the first one opens.
- The search no longer lists every app; with nothing typed it shows your recent files.

**Cloud storage**

- Proton Drive comes first (private, end-to-end encrypted). A service whose folder was found is one **Connect** button; every other service is one **Save a ZIP** button.

**AI settings**

- Model and Base URL are dropdowns (with the models the endpoint reports and an Other entry). The red and yellow key icon is gone.

**Faster**

- A new guide, **Making WorkCraft faster**: panels, the memory guard, browsers, the AI, Ollama settings, iPad. In the documentation and on workcraft.cc/docs.

**Apps**

- SolidCraft 0.44.1, SubCraft 0.4.3, TraceDraw 0.48.0 and NoteCraft 0.0.14 are installed. Fifteen apps that showed the placeholder 0.1.0 now show the version of the source they were built from. Several apps have a newer upstream release without a web build (OxiGuitar 0.21.1, Retake 0.38.0 and others): they need a build, they are not installed yet. Honeydew 0.5.4 (a 1.36 GB web zip) is not installed.

**Be aware:** this is an alpha. Scanning a document on a real iPad, the new cloud rows with a real Proton Drive, Dropbox or MEGA folder, and the model lists of every provider were not tried on real devices or accounts.

Full details: [CHANGELOG.md](https://github.com/visoire/workcraft/blob/main/CHANGELOG.md). Found something? [Open an issue](https://github.com/visoire/workcraft/issues/new/choose).
