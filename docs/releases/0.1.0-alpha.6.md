# WorkCraft 0.1.0-alpha.6

One color setting for the whole workspace.

- **Color** (Settings) sets the accent of the whole workspace: buttons, switches, highlights and the send button. The helper in the chat takes the same color. Blue is the default. The separate switch for the chat accent is gone.

Everything else is as in 0.1.0-alpha.5: [the files of the release](https://github.com/visoire/workcraft/releases/tag/v0.1.0-alpha.5) are the same kinds (`workcraft-local`, `workcraft-web`, `SHA256SUMS.txt`); the hosted version with every app is <https://workcraft.cc/app/>.

Full details: [CHANGELOG.md](https://github.com/visoire/workcraft/blob/main/CHANGELOG.md). Found something? [Open an issue](https://github.com/visoire/workcraft/issues/new/choose).
