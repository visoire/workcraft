# WorkCraft 0.1.0-alpha.5

Set it up with one double-click or with your AI assistant, voice input that works in the browser and on an iPad, one-file backups, safer cloud sync, and a fixed Blip color.

**Get it** (every release has these files)

- **workcraft-local**: run it on your own computer. Unpack it, then double-click **Start WorkCraft.cmd** (Windows) or **Start WorkCraft.command** (macOS), or run `sh start-workcraft.sh` (Linux). The first start sets everything up, starts WorkCraft, opens your browser and offers to start it when you sign in. No administrator rights.
- **workcraft-web**: the browser version as static files, for your own web server. Every app of the catalog is in the hosted version: <https://workcraft.cc/app/>.
- **SHA256SUMS.txt**: checksums of both files.
- **An AI assistant can do it for you:** tell Claude Code, Codex, Cursor, Gemini or another agent "set up WorkCraft" and point it to [SETUP-AI.md](https://github.com/visoire/workcraft/blob/main/SETUP-AI.md).

**New**

- **Voice input:** Handy 0.10.1 is checked with a real transcription. A new **Speech server** in Settings makes the microphone work in the browser and on an iPad on its own: a Whisper server of your own, or Groq and OpenAI with your key (kept in memory only).
- **Back up everything (ZIP)** and **Restore from a backup**: every project, chats and layout in one file; a restore only adds.
- **Safer cloud sync** (ideas from the iCloud sync of OwlLuna): files that iCloud has not downloaded yet are left alone, and a sync that would delete a large part of a project waits for your go-ahead.
- **Blip:** a color change reaches every Blip on screen, and Blue is the workspace blue again.
- **docs/IPAD-TEST-LIST.md:** what to try on a real iPad.

**Be aware:** this is an alpha. The launchers are verified on Windows; the macOS and Linux scripts were not run on those systems. Speech servers, the Speech server test button, Back up and Restore through the iPad share sheet and the Home Screen notice were not tried on a real iPad.
